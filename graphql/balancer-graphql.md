# Balancer GraphQL API

Public GraphQL API used by the Balancer UI and integrators. Provides pools, tokens, swaps, gauges, voting, and analytics across all supported chains.

## Balancer GraphQL API

**Endpoint:** https://api-v3.balancer.fi/

**Documentation:** https://docs.balancer.fi/data-and-analytics/data-and-analytics/api.html

**References:**

- Documentation: https://docs.balancer.fi/data-and-analytics/data-and-analytics/api.html

## Balancer Subgraph

Per-chain GraphQL subgraphs published on The Graph for raw indexed Balancer events.

**Endpoint:** https://api.thegraph.com/subgraphs/name/balancer-labs

**Documentation:** https://docs.balancer.fi/data-and-analytics/data-and-analytics/subgraph.html

**References:**

- Documentation: https://docs.balancer.fi/data-and-analytics/data-and-analytics/subgraph.html
